# IMDB data extraction

> **Archived learning exercise (2020).** Kept as-is; not maintained and not part of the current portfolio.

A web-scraping notebook that collects aggregate box office numbers per film title from Box Office Mojo with `requests` and `lxml` into a pandas DataFrame. The notes section records that the figures differ by 10 to 20 percent from another source. The two notebooks in the repo are copies of the same work.

## Run it

Open `1. Film (BOM).ipynb` in Jupyter with `requests`, `lxml` and `pandas` installed. The site's page structure has likely changed since 2020, so the parsing cells may need updating.
